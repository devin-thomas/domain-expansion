# Domain Expansion — Ideas and Deferred Scope

This file records useful ideas that are intentionally outside the current implementation scope.

Items here are not commitments.

## Cost History

- Track every registration, renewal, transfer, privacy, redemption, and fee event.
- Show historical renewal-price changes.
- Calculate total spent per domain.
- Calculate total spent overall.
- Calculate cost by registrar over time.
- Forecast future spend from historical cadence.

## Automatic Data Sources

- RDAP lookup
- WHOIS lookup where available
- Registrar APIs
- DNS provider APIs
- Renewal-price lookup
- Import from registrar exports
- Parse registrar emails locally
- Detect domains from receipts or screenshots

## Sync and Backup

- iCloud sync
- Google Drive sync
- User-selected folder sync
- Encrypted backups
- Device-to-device transfer
- Optional account-based sync

## Organization

- Smart lists
