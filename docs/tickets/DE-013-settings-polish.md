# DE-013 — Complete Settings, Accessibility, and Release Polish

## Goal

Finish the application as a coherent 1.0 mobile product.

## Scope

- Default reminder offsets.
- Default notification time.
- Default currency.
- Notification permission/status.
- Import/export entry point.
- App and schema version display.
- Accessibility review.
- Loading, empty, and error states.
- App icon, name, and subtitle metadata.
- Release build verification.

## Acceptance Criteria

- Settings persist locally.
- New domains use current defaults.
- Text scaling and semantic labels are usable.
- Destructive actions are confirmed.
- No screen depends only on color.
- App is named Domain Expansion.
- Store-facing subtitle is Website Domain Tracker where supported.
- Release builds succeed for iOS and Android.
- Core manual smoke test passes on both platforms.

## Dependencies

DE-004, DE-005, DE-006, DE-007, DE-012.
