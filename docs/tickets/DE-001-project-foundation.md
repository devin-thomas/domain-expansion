# DE-001 — Create the Flutter Project Foundation

## Goal

Create a clean Flutter application that runs on iPhone and Android and establishes the agreed architecture.

## Scope

- Initialize Flutter project.
- Configure iOS and Android identifiers.
- Add core packages.
- Add feature-oriented folder structure.
- Configure Riverpod and go_router.
- Add light and dark themes.
- Add analyzer/lint configuration.
- Add a basic CI or local verification command.

## Acceptance Criteria

- App launches on iOS Simulator and Android Emulator.
- Dashboard placeholder is the initial route.
- Light and dark mode follow the system.
- `flutter analyze` passes.
- Tests run successfully.
- README includes setup and run commands.

## Dependencies

None.
